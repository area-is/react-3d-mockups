`<Fold>` renders a Galaxy Z Fold - the Z Fold 7, the wide Z Fold 8 or the
Z Fold 8 Ultra, chosen with `variant`; `<FoldMockup>` is the all-in-one
version. One device, two form factors: **open** (default) fills your content
onto the large inner display - a faint crease runs down its center - and
**closed** (`openAngle={false}`) folds to the cover display with the rear
camera pill on the back.

## `<Fold>` vs `<FoldMockup>`

<BareVsMockup object="Fold" kind="fold" slot="Screen" />

```tsx
import { MockupCanvas, Fold, FoldMockup } from 'react-3d-mockups'

// The one-liner: its own canvas, with lighting, a ground shadow, drag-to-orbit
// controls and a camera already framed on the object.
<FoldMockup float style={{ height: 520 }}>
  <YourApp />
</FoldMockup>

// The same model with no stage of its own. Inside a canvas you arrange
// yourself it can be posed, animated, lit and joined by anything else.
<MockupCanvas>
  <Fold rotation={[0, 0.4, 0]}>
    <YourApp />
  </Fold>
</MockupCanvas>
```

## Props

Beyond the [shared screen props](/docs/screen-content) and, on the mockup, the
[shared mockup props](/docs/api):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'fold7' \| 'fold8' \| 'fold8ultra'` | `'fold7'` | Which Galaxy Z Fold to render. `fold7` and `fold8ultra` share the tall book chassis; `fold8` is the generation's wide form factor, opening into a landscape 4:3 tablet. |
| `openAngle` | `boolean \| number` | `true` | How far the book is open. `true` is the unfolded tablet (content on the big inner display, with a center crease), `false` the folded candy-bar (content on the cover display, rear camera pill showing). A number is degrees (0 = shut, 180 = flat) and renders the real Flex Mode book pose: the panels pivot around the Armor FlexHinge while its rounded spine (with the SAMSUNG engraving) stays tangent to both back shells, wrapping the fold at every angle, and your content bends across the crease on two composited planes. The pose is continuous: every angle renders its own pose, and only the extremes hand over to the dedicated folded (~0°) and flat (180°) poses, which draw the crease as one seamless screen. |
| `orientation` | `'portrait' \| 'landscape'` | `'portrait'` | Rotates the device a quarter turn and swaps the virtual display with upright content. On the fold7 and fold8ultra that lays the tablet on its side; on the natively landscape fold8 it stands it upright. |
| `color` | `string` | `'#3a3d42'` | Back panel. Takes a retail colorway id from `FOLD_COLORWAYS[variant]`, which brings that model's frame and hinge with it, or any CSS color - the metal is then derived from it. |
| `resolution` | `number` | per state | CSS pixel width of the active display; height follows the panel aspect. Defaults to the device's own logical grid for whichever screen is showing - see the [device table](/docs/devices). |

## The two states

The active display is whichever screen is showing, so your content maps onto
the inner display when open and the cover display when closed. Switch with a
single prop:

<MockupExplorer
  component="FoldMockup"
  variant="fold7"
  props={{ openAngle: false, autoRotate: true, float: true, color: '#3a3d42', surfaceBackground: '#000' }}
/>

## Any angle in between

`openAngle` takes a number of degrees to pose the book at any openness - the half-open standing
pose with the rounded spine wrapping the fold and your content bending across
the crease:

<MockupExplorer
  component="FoldMockup"
  variant="fold7"
  props={{ openAngle: 110, color: '#47536b', rotation: [0, -0.35, 0] }}
/>

## The models

### Galaxy Z Fold 7

The tall book: a 6.5″ 21:9 cover display folding open into the nearly square
8.0″ inner panel (820×910), with the vertical triple-camera pill top-right on
the back. Retail finishes: `blueshadow`, `jetblack`, `silvershadow`, `mint`.

<MockupExplorer
  component="FoldMockup"
  variant="fold7"
  props={{ color: 'silvershadow', rotation: [0, -0.3, 0] }}
/>

## Colorways

Pass an id from that model's catalog in `FOLD_COLORWAYS` for the retail finish
- the frame and hinge come with it. A CSS color gets metal derived from it
instead, so `color="#4a5568"` needs nothing else.
