shipped here as Latin-subset variable WOFF2 files.

| File | Family | Source |
| --- | --- | --- |
| `InterVariable.woff2` | Inter, by Rasmus Andersson | https://rsms.me/inter/ |
| `JetBrainsMono-Variable.woff2` | JetBrains Mono, by JetBrains | https://www.jetbrains.com/lp/mono/ |
| `Fraunces-Variable.woff2`, `Fraunces-Italic-Variable.woff2` | Fraunces, by Undercase Type | https://github.com/undercasetype/Fraunces |
| `NotoSansKR-Variable-KSX1001.woff2` | Noto Sans KR, by Google (subset to the 2,350 KS X 1001 syllables with `pyftsubset`) | https://github.com/google/fonts/tree/main/ofl/notosanskr |
